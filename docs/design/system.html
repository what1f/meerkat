安静、精确，每个像素都有用。

把指针放到工卡上，再点开它。Esc 返回。

引导

第一次打开时的五步。从工位开始，中间几步在板上挂出要设置的东西，最后回到工位，直到第一位成员在飞书里回你。

原则

判断一个设计对不对，先看这六条。

一

不解释直觉能懂的

能用位置、头像、图标、状态点表达的，不写字。文字只留给缺了就看不懂的地方。

二

在原地完成

点哪里就在哪里编辑。设置改完自动保存；成员的改动要同步到飞书，改了才出现「保存」。新建的东西出现在它该在的位置，进度也显示在那里。

三

一种需求一个组件

固定的两三项用 Segmented，会变多的用 Select，能输入的用 Combo；Switch 只出现在设置行；空位一律是虚线框。没有第二种写法。

四

色彩留给生命

界面是中性的白和墨色。颜色来自狐獴头像和状态点；品牌紫只用于聚焦、选中和开关。

五

动效只说明变化

出现、离开、状态切换才动，120 到 320 毫秒，只在出现时带一点回弹。只有正在进行的事情才循环。

六

说用户的话

成员、团队、飞书、工区。界面上不出现 Agent、App、Bot、ID、IM。

组件

每个组件只有一份实现，变体只有这里列出的。下面的组件都可以点。

Button

胶囊形。primary 一屏最多一个；danger 只用于确认破坏性操作。

Input · Doc · 就地编辑

输入框没有边框，聚焦时出现品牌紫的光圈。就地编辑的文字平时就是文字。

Switch · Segmented · Select · Combo

Switch 只用于设置行的开关；固定的两到四项用 Segmented；会增加的列表用 Select；既能选又能自己填的用 Combo，输入即过滤，回车采用。

Menu：10 圆角、4 内边距、菜单项 30 高 6 圆角。选中用勾，危险项用红字。

Choice

只用于一次性的、要靠品牌图标认出来的少量选项，比如连接飞书还是 Telegram。会变多的列表不用它。

Group · Row

唯一的容器。行高 40，标签在左，控件在右，行间是细线。不再有面板套面板。

Badge

成员是挂在洞洞板上的工卡：白卡、冲孔、夹子，颜色只来自头像；名字、岗位、一句话介绍，底边是 AI。指针经过时轻轻晃一下，点开后同一张卡放大，直接在卡上改。

QR tag

二维码挂成吊牌，在原地变化，不弹错误。扫码后变暗并显示扫码人，过期时刷新按钮就在码上，登录后翻成你的工卡。

Reaction

成员读到消息时先回一个表情。行尾就是当前表情，点开换；第一格虚线框表示不回复。用飞书自己的表情图。

Avatar picker

上传在最前；内置狐獴随后。新成员默认分到一只还没人用的。

Dialog · Confirm · Toast

弹窗只用于需要专注的新建。确认框只用于不可撤销的操作；能撤销的用 toast。

变化

和现状相比改了什么。现状见 current.html。

导航侧栏「成员 / 团队 / 设置」，工作区切换器在页头右侧团队切换放在侧栏顶部；侧栏是「成员 / 团队 / 工区」，「设置」在底部
成员296 × 360 名片，悬停出编辑和删除；编辑弹窗 980 宽，左表单右预览，底部保存一面洞洞板，没有页面标题。工卡用挂绳挂在挂钩上，指针经过时轻晃；第一张是你自己，空挂钩就是添加。按住工卡拖动可以调整顺序，其他卡会让位；你自己的卡固定在第一位。点开后板上挂出一台暖白色的操控台，工卡挂在右边当预览，头像、名字、岗位、介绍直接在卡上改。操控台顶上站着 TA 的形象，角上贴着已读表情；中间的黑色屏幕显示 AI、模型、工区和思考强度，点开是四列选择器：工区、AI、模型、思考，后一列由前一列决定，能搜索，思考强度是一根挡杆，档位数随模型变化。性格是插在槽里的一张卡，长了就藏进槽里，点一下抽出来写。高级从操控台底下拉出抽屉。改动要同步到飞书，所以改了才出现「保存」；没保存就返回，会问保存还是放弃。私聊、暂停、删除和「保存」是操控台下沿的一排实体按键，「保存」有改动时亮绿灯
首次引导四步向导，带步骤条，要填工作区 ID、Agent ID 等五屏，同一面洞洞板，每屏挂上一样东西：欢迎页是一张工位和一段飞书对话；连接时二维码挂成吊牌，扫完原地翻成你的工卡；选 AI 在操控台屏幕上自动测一次；第一位成员只填名字，「高级设置」拉出操控台。登录只扫这一次，以后加成员不再扫码。Telegram 只粘贴管理 bot 的 Token；你的工卡先是空白的，扫码确认第一位成员时顺带认出你，空白卡翻成你的工卡。之后每加一位成员都要扫码确认。终点是 TA 在飞书里回你第一句话
添加成员820 宽弹窗，四步，填 Agent ID、显示名称、工区、Agent、模型、思考等级没有弹窗：点板上的空挂钩，一张空白工卡飞到前面，随机头像，直接写名字，按回车或「添加」。卡挂回板上，原地显示创建进度
预览与测试编辑弹窗右侧的静态名片预览；没有测试工卡本身就是预览，改什么立刻看到。对话以后做成单独的私聊页，从顶栏的消息图标进入
表情表单里一个 36 px 圆按钮，弹出 20 格网格操控台角上的一张贴纸，点开换；不回复时没有贴纸，下沿多一个笑脸键，选了表情就贴回角上
团队设置分组里套 IM 面板，再套任务面板；底部保存按钮同一面洞洞板：团队名写在贴在板子上方的纸条上，点了就能改；挂着一块「上班／下班」的牌子，点一下翻面；下班后成员都不回消息，工区里只剩空椅子，屏幕全黑；规约写在挂着的吊牌上；任务清单是夹在木质写字板上的真实清单，能勾、能加，停用后变回虚线空位。挂牌、吊牌、清单都能拖到别的孔上。飞书账号移到你自己的工卡上
你自己团队页里的飞书身份卡扫码登录的人就是负责人，名字、头像、岗位都从飞书同步，这里不编辑。挂绳是品牌蓝紫色，成员的是黑色，别的都一样。工卡和成员一样能拖动排序。点一下工卡翻到背面，背面只有飞书标志和「同步资料」「切换账号」两栏，不显示组织名；正面没有卡底，点别处翻回来；不能删除
运行状态在「设置 → 状态」，红绿描边按钮团队页墙上的开关，开着时指示灯亮；侧栏团队标记上的点
工区在设置页里从成员身后看过去的一排排工位。每个工区一段，标题是名字和状态点，段与段之间一条细线。成员各有一张桌子，有的是笔记本架在显示器旁，有的是显示器配 Mac mini，能对上工区机型就用同款。屏幕说明在做什么：回复中屏幕上在打字，需要处理时屏幕变红亮「!」，暂停时趴在桌上睡、屏幕变暗。离线的工区里成员都在睡，屏幕黑着。没有成员的工区不摆桌子。按住成员会被拎起来晃，放到另一排就换了工区。最后一行是添加
侧栏固定宽度红绿灯旁的按钮一下把侧栏整个收起，再点回来。拖右边缘调宽窄，往左拖过一段就只留图标，悬停显示名字，收起按钮挪到红绿灯下方，团队切换等展开后再用，双击边缘也能切换。团队名前不放头像和状态点
浅色和深色只在设置页里右上角垂一根拉线，往下拉一下就开关灯，松手弹回去。设置页里的选项还在，可以跟随系统
形象没有形象和头像分开：头像用在飞书和工卡上，形象是成员在工区里的样子。每个形象是一整套状态帧，换形象就是换一整套，不拼装。成员资料里能换，也能导入别人做的形象包
