# Design

- [design-system.md](design-system.md): visual language, tokens, components, copy
  rules, and the current gaps against them.
- [onboarding.md](onboarding.md): first-run flow, user story, screen-by-screen
  decisions, and implementation plan.
- `onboarding/`: approved onboarding mockups (generated concept art, not
  screenshots).
- `avatars/`: built-in member avatar set overview.
- `figures/`: built-in figure sprite sets for the 工区 office, one folder per
  figure (see [Figures](design-system.md#figures)).
- `office/`: shared 工区 office art: desk setups with transparent screens,
  and the empty chair shown when the team is off duty.
- `system.html`: interactive prototype of the design system and every page.
- `current.html`: the shipped UI as it is today, for comparison with
  `system.html`.

Mockups show intent. When a mockup and this text disagree, the text wins.
