# Code of Conduct

We want Meerkat to be a welcoming, practical, and respectful project.

Contributors are expected to discuss ideas and review work in good faith, focus
criticism on the work, respect privacy, and avoid harassment, discrimination,
threats, or the publication of another person's private information.

Project maintainers may edit or remove contributions and communication that do
not meet these standards. Report sensitive conduct concerns through the same
private channel described in `SECURITY.md`.
